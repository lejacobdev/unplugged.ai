Edit a picture

One-time setup needed. The image model (FLUX.1 Kontext [dev], about 34 GB) isn't installed yet.
1. Open huggingface.co/black-forest-labs/FLUX.1-Kontext-dev, sign in and accept the license (it is a non-commercial license, so check it covers how you plan to use the cover).
2. Run ./setup_image_model.sh in the project folder. It logs in, downloads the model once, and saves an 8-bit copy for offline use.
After that, editing works with no internet at all.
